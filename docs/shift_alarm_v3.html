⚠️ 저작권 보호를 위해 본인이 소유한 음원 파일만 선택할 수 있어요. 인터넷에서 내려받은 음악을 임의로 사용하면 저작권법에 위배될 수 있으니, 직접 녹음했거나 정식으로 구매·보유한 파일만 넣어주세요.

🔑 Claude API 키›

사진 자동 분석 기능에 필요해요. console.anthropic.com에서 발급받은 키를 입력하세요. 키는 이 기기의 브라우저에만 저장되고 서버로 전송되지 않아요.

📲 홈 화면에 추가하기›
iOS(사파리): 하단 공유 버튼 → "홈 화면에 추가"
Android(크롬): 우측 상단 메뉴(⋮) → "홈 화면에 추가" 또는 앱 설치 팝업
홈 화면에 추가하면 앱처럼 전체 화면으로 실행되고, 알림도 더 안정적으로 동작해요.
🔔 백업 알림 서버›

앱을 완전히 꺼둬도 알람이 오도록, 알림 권한만 허용하면 자동으로 백업 서버에 연결돼요. 따로 입력할 건 없어요.

미설정

직접 운영하는 서버가 따로 있는 경우에만 아래에 주소를 입력하세요. 평소엔 비워두시면 돼요.

🔋 배터리 최적화 해제 (Android)›
백업 알림을 켰어도 제조사 배터리 절전 기능이 브라우저 앱을 재워버리면 알림이 늦게 오거나 씹힐 수 있어요. 아래 설정으로 예외 처리해 주세요.

삼성(One UI): 설정 → 배터리 및 디바이스 케어 → 배터리 → 백그라운드 사용량 제한 → Chrome(또는 사용 브라우저) 찾아서 "제한 없음"으로 변경

샤오미(MIUI): 설정 → 앱 → 앱 관리 → Chrome → 배터리 절약 → "제한 없음"

일반 Android: 설정 → 앱 → Chrome → 배터리 → "최적화 안 함"
⚠️ 데이터 초기화›
